SENTINEL {{ .Chart.AppVersion }} est déployé ({{ .Release.Name }}).

{{ if .Values.config.strictMode -}}
Mode STRICT actif : le pod refuse de démarrer si la persistance est
absente ou si les clés cryptographiques et les tokens ne sont pas
définis. Si les pods redémarrent en boucle, lisez d'abord les logs :

  kubectl logs -n {{ .Release.Namespace }} -l app.kubernetes.io/instance={{ .Release.Name }} --tail=20

Chaque manque y est nommé explicitement.
{{- else -}}
ATTENTION : mode strict désactivé. SENTINEL peut démarrer sans
persistance et tourner en mémoire — les journaux d'audit ne
survivraient pas à un redémarrage. Réservé aux démonstrations.
{{- end }}

{{ if and (not .Values.secrets.existingSecret) .Values.secrets.create -}}
Le Secret a été créé depuis values.yaml. En production, préférez
`secrets.existingSecret` : un secret dans un values.yaml finit
versionné dans Git.
{{- else if not .Values.secrets.existingSecret -}}
Aucun Secret n'est référencé ({{ "secrets.existingSecret" }} vide et
{{ "secrets.create" }} à false). Créez-le avant que les pods démarrent :

  kubectl create secret generic {{ include "sentinel.fullname" . }} \
    --from-literal=vault_master_key=$(openssl rand -hex 32) \
    --from-literal=audit_hmac_key=$(openssl rand -hex 32) \
    --from-literal=admin_token=$(openssl rand -hex 24) \
    --from-literal=dashboard_token=$(openssl rand -hex 24) \
    --from-literal=database_url='postgresql://…'
{{- end }}

{{ if and .Values.config.strictMode (not .Values.config.corsOrigins) -}}
ATTENTION : `config.corsOrigins` est vide et le mode strict est actif —
les pods refuseront de démarrer. Indiquez l'origine exacte de la console,
par exemple https://sentinel.mondomaine.fr (jamais `*` : la console
s'authentifie par cookie).
{{- end }}

{{ if .Values.dashboard.enabled -}}
Console d'administration :

  kubectl port-forward -n {{ .Release.Namespace }} svc/{{ include "sentinel.fullname" . }}-dashboard 8080:{{ .Values.dashboard.service.port }}
  # puis http://localhost:8080

Elle relaie l'API sur `/api`, donc sur la même origine : rien à ouvrir
côté CORS tant que vous ne la déplacez pas sur un autre domaine.
{{- else -}}
Console désactivée (`dashboard.enabled=false`) : l'API est déployée
seule.
{{- end }}

Accès direct à l'API :

  kubectl port-forward -n {{ .Release.Namespace }} svc/{{ include "sentinel.fullname" . }} {{ .Values.service.port }}:{{ .Values.service.port }}
  curl http://localhost:{{ .Values.service.port }}/health

Rapport de conformité (token dashboard requis) :

  curl -H "X-Dashboard-Token: <token>" http://localhost:{{ .Values.service.port }}/compliance/report
